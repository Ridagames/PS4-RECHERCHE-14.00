Grille de recherche
  • Durée de vie : Ref / RefPtr / WeakPtr / WeakHashSet / retain / release / destruction.
  • Réentrance : callbacks, Promise, thenable, event, layout synchrone, mutation DOM.
  • Itération : copie de conteneur, invalidation d'itérateur, suppression pendant parcours.
  • Validation : bounds checks, null checks, type checks, contains(), guards.
  • Concurrence : tâches asynchrones, dispatch, locks et états partagés.
